Ashen Relics 0.7.3 Manifest / Whisper Patch

Changes:
- Relic whispers now fire 3 minutes after that specific relic is found.
- Moldy Shipping Manifest whisper waits until all 3 manifest pieces are recovered.
- Removed the 10-20 minute random global whisper timer.
- Tightened the first two strongbox search radii to reduce through-ship unlock prompts.
- Added a wider fallback for the final/third manifest to prevent getting stuck at 2/3.
- Added /ar fixmanifest as a safety repair if an existing save is already stuck at 2/3.

Note:
Vanilla WoW can still let your cursor target some ship objects through walls. The addon cannot change Blizzard object targeting, but this patch prevents Ashen Relics from awarding progress unless its own location checks pass.
